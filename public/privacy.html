Last updated: November 21, 2026 · Česky níže

Overview

DoggioWars (com.ol1n.doggiowars) is a free flying game by Oldřich Vořechovský (ol1n), available as an iOS and Android app and on the web. It has no accounts, no ads, no analytics, no tracking SDKs and no in-app purchases. The game does not collect, send or sell any personal data.

What stays on your device

Your settings (language, controls, quality, volume, an optional Twitch bridge address) are saved in the app's local storage on your device. They never leave it. Uninstalling the app or clearing site data deletes them. The world is generated on the device; nothing about your game is uploaded.

Network

  • App (iOS, Android): all game files are inside the app package. The game makes no network requests on its own.
  • Web version: the game is downloaded from GitHub Pages. Like every web host, GitHub processes your IP address to deliver the files (see GitHub's privacy statement). After the first load the game works offline.
  • Twitch chat bridge (optional, off by default): streamers can enter the address of their own chat bridge service in the command line (/bridge). The game then periodically asks that address for chat events (for example "spawn a dragon"). The request goes only to the address you entered and carries nothing about you. The developer does not run or receive data from any such service.
  • Links: "Source code", "Privacy" and the licence link in Settings open in your browser.

Children

The game collects no data from anyone, including children.

Changes

If a future version starts processing any data, this page will be updated before that version is released.

Nastavení (jazyk, řízení, kvalita, hlasitost, případná adresa Twitch bridge) se ukládá do místního úložiště aplikace ve vašem zařízení a nikam se neodesílá. Odinstalace aplikace nebo smazání dat webu ho odstraní. Svět se generuje přímo v zařízení; nic z vaší hry se nikam nenahrává.

Síť

  • Aplikace (iOS, Android): všechny soubory hry jsou přímo v balíčku aplikace. Hra sama žádné síťové požadavky nedělá.

Provozovatel hry žádnou takovou službu neprovozuje a žádná data z ní nedostává.
